# 雾眠筹码

直接打开本目录的 index.html，无需安装依赖或运行服务。页面为 #home、#music、#photos 和 #friends。

网站以此目录中的第二版为基础继续维护。上一级 index.html 和原 compare.html 均自动进入此版本。第一版已退出使用，界面不再提供版本对比入口。

本目录独立保存 HTML、CSS、脚本、48 首歌曲资料、本地音乐与装饰资源。音乐保留无封面布局，《追逐阿航》保持首推且可本地播放，其余使用网易云链接。收藏列表支持按歌名或歌手搜索；摄影已有 4 张图片和 1 段视频，素材位于 assets/gallery/。

所有装饰资源均来自用户提供素材清单中的 Make Aero：云天/气泡背景、水下背景，及按其 MIT 代码调整的玻璃球、窗体、按钮。未使用第一版的其他图库图片，未新增其他素材来源。字体和符号为系统文字。完整来源、参数、许可在 credits.html 与 ASSETS.md。

文案、照片和音乐资料在 content.js；配色、玻璃材质和响应式在 styles.css；页面与交互在 app.js。播放器只在点击后出现并播放，可暂停、拖动进度、调整音量或收起；切换三页时继续播放。背景可暂停，跟随系统减少动态效果，并在标签页隐藏时暂停动画。照片布局、背景开关和音量会在浏览器允许时记住。

摄影布局支持宽幅和紧凑两种密度。添加真实照片后，可点击查看大图，用前后按钮或左右方向键翻页，按 Escape 关闭。图片加载失败时显示简短提示。

默契测试位于 #friends，十道选择题全部在浏览器本地计算，只显示本次测试的了解程度百分比，不收集姓名、不注册、不联网、不保存结果。没有好友名册和挚友相册。
